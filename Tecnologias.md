# Tecnologías

- **VsCode**: Editor de texto usado para realizar el código y organizar nuestro proyecto.

- **Git**: Herramienta para manejo y organización local de nuestro proyecto.

- **GitHub**: Herramienta web para visibilidad y organización remota de nuestro proyecto.

- **HTML**: Lenguaje de programación web para estructurar la base de nuestra página web.

- **CSS**: Lenguaje en cascada para estilizado de nuestra página web.
